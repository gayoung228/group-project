# 로버 시험 절차

코드가 빌드되는 것과 실제 차가 안전하게 동작하는 것은 별개의 확인 항목이다.
아래 순서대로 범위를 넓히면 어느 부품에서 문제가 생겼는지 찾기 쉽다.

## 1. 빌드 확인

```bash
cmake --preset Debug -DROVER_FIRMWARE_MODE=ROVER
cmake --build --preset Debug
```

필요하면 `HEADING_TEST`, `IR_TEST`, `VL53_TEST`도 각각 빌드한다. 시험 후에는
`ROVER` 모드로 돌려놓는다.

## 2. 바퀴를 띄운 시험

1. 로버 바퀴를 바닥에서 띄우고 전원을 켠다.
2. 초기화 로그에서 모터, 엔코더, MPU6050, VL53L0X L/F/R, IR 준비 상태를 확인한다.
3. 느린 속도로 시작한 뒤 정지 명령이 즉시 동작하는지 확인한다.
4. 좌우 바퀴를 손으로 각각 돌려 실제 RPM이 연속적인 값으로 변하는지 확인한다.
5. 펄스를 멈추면 약 200 ms 뒤 실제 RPM이 0이 되는지 확인한다.

합격 기준: 모터가 멈춘 상태에서 목표 RPM은 0이며, 회전 중 실제 RPM이 예전처럼
0·30·60·90으로만 변하지 않는다.

## 3. 평지 직진 시험

1. 앞쪽에 최소 2 m 공간을 둔다.
2. 차체를 정렬하고 시작 명령을 보낸다.
3. `NORMAL` 로그에서 목표 RPM, 실제 RPM, yaw를 확인한다.
4. 한쪽으로 계속 쏠리거나 yaw가 계속 증가하는지 관찰한다.

실제 RPM은 펄스마다 조금 흔들릴 수 있다. 한 번의 값보다 1~2초 동안의 좌우 차와
차량의 실제 궤적을 함께 판단한다.

## 4. 세 거리센서 단독 확인

전체 주행 전에 `VL53_TEST` 모드로 각 센서를 따로 가린다.

1. 손이나 평평한 판을 LEFT 앞에만 놓고 L 값만 변하는지 확인한다.
2. 같은 방법으로 FRONT와 RIGHT의 위치·주소 매핑을 확인한다.
3. 200, 500, 1000 mm에서 줄자로 잰 거리와 로그를 비교한다.
4. 센서 앞 물체를 없앴을 때 `--` 또는 범위 초과가 나오고 통신 오류와 구분되는지 확인한다.
5. 센서 하나의 XSHUT 또는 I2C 선을 끊었을 때 전체 주행이 시작되지 않는지 확인한다.

센서 이름이 물리 위치와 바뀌었거나 한 센서만 계속 0이면 자율 회피 시험으로 넘어가지 않는다.

## 5. 회피 판단만 확인

바퀴를 띄우거나 모터 전원을 분리한 상태에서 `ROVER` 로그를 먼저 확인한다.

1. 정면 장애물을 500 mm 밖→안으로 천천히 이동한다.
2. 새 측정 3회 뒤 `TURN-OUT`과 LEFT/RIGHT 선택 로그가 나오는지 확인한다.
3. 선택된 방향을 이벤트 중간에 좌우 거리를 바꿔도 유지하는지 확인한다.
4. 안쪽 센서를 700 mm 이하로 유지해 `FOLLOW-EDGE` 진입을 확인한다.
5. 안쪽 센서를 1000 mm 이상으로 바꿔 `ALIGN-OPEN` 진입을 확인한다.

## 6. 첫 저속 장애물 회피 시험

1. 좌우로 최소 1 m 이상 열린 곳에 넓고 평평한 벽 하나를 놓는다.
2. STOP 리모컨을 즉시 누를 사람이 차량 옆에서 따라간다.
3. `TURN-OUT → CURVE-OUT → FOLLOW-EDGE → ALIGN-OPEN → CLEAR-BODY → RETURN-YAW`
   순서를 로그와 실제 궤적으로 확인한다.
4. 어느 바퀴의 목표 RPM도 회피 중 65 RPM 아래로 내려가지 않고, 실제 바퀴가 멈추지 않는지 확인한다.
5. `TURN-OUT` 완료 뒤 약 1000 mm에서 `RETURN-YAW`가 시작되는지 확인한다. 센서 조건에
   따라 중간 상태 일부는 건너뛸 수 있다.
6. `RETURN-YAW`에서 좌우 목표 RPM의 부호가 반대이고, 추가 전진 없이 제자리에서
   원래 Yaw로 복귀하는지 확인한다.
7. 원래 Yaw 복귀 때 차체 뒤가 장애물 끝과 최소 100 mm 이상 떨어지는지 확인한다.

첫 시험에서는 거리·각도 값을 바꾸지 말고 실패한 상태와 그 순간의 L/F/R, Yaw,
목표/실제 RPM을 기록한다. 한 번에 한 종류의 튜닝값만 바꾼다.

## 7. 비상정지·짧은 탈출 시험

1. 차량을 낮은 속도로 움직이며 측면에 큰 판을 접근시킨다.
2. 180 mm 이하에서 `SAFETY-STOP`이 되는지 확인한다.
3. 정면과 반대쪽이 350 mm 이상 열려 있을 때만 `SAFETY-TURN`으로 넘어가는지 확인한다.
4. 통로가 막혀 있으면 움직이지 않고 `FAILED`가 되는지 확인한다.
5. 탈출 성공 시 열린 방향 45도 제자리 회전, 400 mm 전진, 원래 Yaw 복귀 순서를 확인한다.

사람 손을 실제 충돌 시험 물체로 사용하지 않는다.

## 8. 방지턱 시험

낮은 경사부터 시작한다. 이벤트 진입, 출력 증가, 내리막 감속, 자세 복구, 정상 모드
복귀 순서가 로그와 실제 동작에서 일치하는지 확인한다. 차체가 넘어질 수 있는 높은
장애물은 사용하지 않는다.

## 9. 연속 이벤트 시험

```text
START
 → 벽 회피 → 정상 직진
 → 다른 벽 회피 → 정상 직진
 → 방지턱 CLIMB/DESCENT/LEVEL
 → 정상 직진
 → 리모컨 STOP
```

벽 개수를 세거나 방지턱 순서를 기다리는 단계는 없다. 낮은 방지턱이 정면 거리센서에
잡히지 않는 높이인지 먼저 확인한다. 각 이벤트 완료 후 정상 직진으로 복귀하는지,
마지막에 리모컨 STOP을 누르면 목표 RPM과 PWM이 모두 0이 되는지 확인한다.

## 기록할 값

- 펌웨어 커밋 ID와 빌드 모드
- 배터리 전압과 선택한 속도
- 목표/실제 좌우 RPM
- yaw와 X/Y/Z 자세
- 장애물 거리와 상태 전환 시점
- 성공 여부와 실제 현상

## 10. RAW 100% 모터 시험

차량 바퀴를 먼저 공중에 띄우고 시험한다.

1. UART `p`와 IR `100+`를 각각 눌러 좌우 PWM 로그가 모두 100%인지 확인한다.
2. 자이로 자세, 목표 RPM, 거리센서값이 모터 출력을 바꾸지 않는지 확인한다.
3. `x`와 IR STOP을 각각 눌러 두 모터가 즉시 0%로 정지하는지 확인한다.
4. 바닥 시험은 전방이 충분히 열린 곳에서 STOP 담당자가 바로 옆에 있을 때만 짧게 수행한다.
