# 로버 시험 절차

코드가 빌드되는 것과 실제 차가 안전하게 동작하는 것은 별개의 확인 항목이다.
아래 순서대로 범위를 넓히면 어느 부품에서 문제가 생겼는지 찾기 쉽다.

## 1. 빌드 확인

```bash
cmake --preset Debug -DROVER_FIRMWARE_MODE=ROVER
cmake --build --preset Debug
```

필요하면 `HEADING_TEST`, `IR_TEST`, `VL53_TEST`도 각각 빌드한다. 시험 후에는
`ROVER` 모드로 돌려놓는다.

## 2. 바퀴를 띄운 시험

1. 로버 바퀴를 바닥에서 띄우고 전원을 켠다.
2. 초기화 로그에서 모터, 엔코더, MPU6050, VL53L0X, IR 준비 상태를 확인한다.
3. 느린 속도로 시작한 뒤 정지 명령이 즉시 동작하는지 확인한다.
4. 좌우 바퀴를 손으로 각각 돌려 실제 RPM이 연속적인 값으로 변하는지 확인한다.
5. 펄스를 멈추면 약 200 ms 뒤 실제 RPM이 0이 되는지 확인한다.

합격 기준: 모터가 멈춘 상태에서 목표 RPM은 0이며, 회전 중 실제 RPM이 예전처럼
0·30·60·90으로만 변하지 않는다.

## 3. 평지 직진 시험

1. 앞쪽에 최소 2 m 공간을 둔다.
2. 차체를 정렬하고 시작 명령을 보낸다.
3. `NORMAL` 로그에서 목표 RPM, 실제 RPM, yaw를 확인한다.
4. 한쪽으로 계속 쏠리거나 yaw가 계속 증가하는지 관찰한다.

실제 RPM은 펄스마다 조금 흔들릴 수 있다. 한 번의 값보다 1~2초 동안의 좌우 차와
차량의 실제 궤적을 함께 판단한다.

## 4. 장애물 회피 시험

1. 정면 0.5~1 m에 넓고 평평한 장애물을 놓는다.
2. 감지 후 정지하는지 확인한다.
3. 분할 회전, 우회 전진, 복귀 회전, 정상 직진 순서의 상태 로그를 확인한다.
4. 센서 범위를 벗어난 `8191 mm`는 장애물 없음으로 처리되는지 확인한다.
5. 거리센서 오류가 지속될 때 안전 정지하는지 확인한다.

## 5. 방지턱 시험

낮은 경사부터 시작한다. 이벤트 진입, 출력 증가, 내리막 감속, 자세 복구, 정상 모드
복귀 순서가 로그와 실제 동작에서 일치하는지 확인한다. 차체가 넘어질 수 있는 높은
장애물은 사용하지 않는다.

## 기록할 값

- 펌웨어 커밋 ID와 빌드 모드
- 배터리 전압과 선택한 속도
- 목표/실제 좌우 RPM
- yaw와 X/Y/Z 자세
- 장애물 거리와 상태 전환 시점
- 성공 여부와 실제 현상
