# 배선과 전원 점검

정확한 핀 번호는 [pinmap.md](pinmap.md)를 기준으로 한다.

## 전원의 역할

```text
모터 배터리 (+) ──→ TB6612FNG VM ──→ 모터
NUCLEO 3.3 V ─────→ 센서와 TB6612FNG VCC

모터 배터리 (-) ─┐
NUCLEO GND ───────┼── 모두 같은 기준 전압(공통 GND)
센서 GND ─────────┘
```

GND는 전류가 모두 한 구멍으로 들어가야 한다는 뜻이 아니라, 전압을 재는 기준이
전기적으로 서로 연결되어야 한다는 뜻이다. 브레드보드 GND 레일을 여러 개 쓴다면
레일끼리 점퍼선으로 연결한다.

## 연결 순서

1. 모든 전원을 끈다.
2. 공통 GND부터 연결한다.
3. 센서 전압이 3.3 V 규격인지 확인하고 VCC를 연결한다.
4. 신호선과 I2C SDA/SCL을 연결한다.
5. 모터 드라이버의 논리 전원 VCC와 모터 전원 VM을 구분해 연결한다.
6. 멀티미터로 3.3 V와 GND 사이 단락이 없는지 확인한 뒤 전원을 켠다.

## 주의 사항

- 모터 전원을 NUCLEO의 3.3 V 또는 5 V 핀에서 공급하지 않는다.
- STM32 입력 핀에는 5 V 엔코더 출력을 바로 연결하지 않는다. 모듈 출력 전압을
  먼저 측정하고 필요하면 레벨 시프터나 분압 회로를 사용한다.
- MPU6050의 AD0를 GND에 연결하면 주소는 `0x68`이다.
- I2C SDA와 SCL은 3.3 V로 풀업되어야 한다.
- 배선을 꽂은 순간 다운로드가 실패하면 펌웨어보다 전원 단락, 과전류, 디버그 핀
  간섭을 먼저 의심하고 즉시 전원을 끈다.
