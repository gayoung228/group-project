# 현재 구현 기능

이 문서는 현재 `feature/control` 작업 트리의 코드를 기준으로 작성한다.
`구현 완료`는 코드와 빌드가 준비됐다는 뜻이며, 실물 차량의 노면·배터리·하중에
따른 수치는 반복 주행으로 추가 조정해야 한다.

## 전체 동작 흐름

```text
전원 ON
  ↓
모터·엔코더·MPU6050·VL53L0X 3개·IR 초기화 및 결과 출력
  ↓
START 명령 대기
  ↓
자이로 직진 보정 + 바퀴 RPM 제어
  ├─ 벽 감지 → 넓은 쪽 곡선 회피 → 가장자리 추종 → 원래 Yaw 복귀 → 직진
  ├─ 낮은 방지턱 → 오르막 가속 → 내리막 감속 → 평지 확인 → 직진
  └─ 센서·모터 이상 → 재시도 또는 안전 정지
```

## 1. 시스템 초기화와 진단 로그

- 모터 드라이버, 좌·우 엔코더, MPU6050, VL53L0X, IR 수신기를 순서대로 초기화한다.
- 각 장치의 성공 여부를 `[INIT] ... OK/ERROR` 형태로 따로 출력한다.
- MPU6050은 전원 안정화 뒤 각 I2C 거래와 전체 초기화를 최대 3회 재시도한다.
- VL53L0X 주소 할당이 하나라도 실패하면 세 XSHUT을 모두 LOW로 리셋하고
  `LEFT → FRONT → RIGHT` 주소 할당을 처음부터 최대 3회 다시 수행한다.
- 최종 실패 로그에는 센서 이름, 실패 단계, HAL 상태, I2C 오류값을 함께 출력한다.
- 준비가 끝나면 공중 실측값에 저전압 여유를 더한 RPM 단계 `65 / 70 / 78 RPM`을 출력한다.
- `ap_main.c`는 실행할 앱만 선택하고 실제 기능은 `rover_app`과 하위 모듈에 맡긴다.

## 2. UART와 IR 리모컨 명령

UART와 IR 명령은 같은 내부 함수를 사용하므로 출발·정지 동작이 동일하다.

| 기능 | UART | IR 명령 코드 |
|---|---:|---:|
| 주행 시작 | `s` | `0xC2` |
| 정지 | `x` | `0x90` |
| 현재 자세를 0도 기준으로 재설정 | `z` | `0xE2` |
| 세 방향 거리 한 번 출력 | `d` | 임시 보정 버튼으로 전환됨 |
| 저속 65 RPM | `1` | `0x30` |
| 보통 70 RPM | `2` | `0x18` |
| 고속 78 RPM | `3` | `0x7A` |

- NEC 방식 IR 프레임의 주소, 명령, 반전 바이트를 확인한다.
- 같은 버튼을 계속 누를 때 들어오는 Repeat 신호는 새 명령으로 중복 실행하지 않는다.
- 인터럽트에서는 캡처 시간만 저장하고 해석과 모터 명령은 메인 루프에서 수행한다.
- 자이로 기준 초기화 버튼(`z`/`0xE2`)을 2초 안에 3회 누르면 차량을 정지하고
  XSHUT으로 거리센서 3개를 재초기화한다. 완료 뒤 START를 다시 눌러 출발한다.
- 현재 IR `DISTANCE` 버튼은 무선 보정 시험을 위해 UART `c`와 같은 동작으로 임시
  연결되어 있다. 한 번은 보정 대기, 두 번째는 보정 시작, STOP은 취소다.

## 3. 모터와 바퀴 속도 제어

- 좌·우 바퀴별 목표 RPM과 실제 RPM을 비교하는 폐루프 PID 제어를 사용한다.
- 정지 마찰을 넘기기 위해 일반 출발은 100% 출력을 200 ms 적용한다. 제자리 회전은
  각도 오버슈트를 줄이기 위해 80 ms만 적용한다.
- 모터가 돌기 시작하면 목표 RPM에 맞는 일반 제어로 전환한다.
- 주행 또는 제자리 회전 중 한쪽 실제 RPM이 30 RPM 아래로 2초간 유지되면 시동
  시퀀스를 한 번 다시 실행한다.
- 재시동 후에도 다시 2초 동안 RPM이 회복되지 않으면 모터 오류를 출력하고 안전 정지한다.
- 직진 방향 보정은 먼저 필요한 쪽 바퀴의 RPM을 올린다. 해당 모터가 실측 상한에
  닿으면 반대쪽을 조금 낮추되 65 RPM 아래로는 내리지 않는다.
- 순간적인 자이로 오차가 유턴으로 이어지지 않도록 좌우 목표 RPM 차이를 최대
  12 RPM으로 제한한다. 회피 중 기본 RPM은 모터가 실제로 도는 65 RPM 아래로 내리지 않는다.
- 목표가 0이 아닌 동안 PID의 최종 PWM도 실측 최저 출력 70% 아래로 내려가지 않는다.
- 누적 엔코더 차이를 사용한 좌·우 진행량 동기화가 구현되어 있다.
- 모든 최종 모터 명령은 `drive`를 거쳐 출력된다. 장애물 회전 같은 직접 출력도
  `drive_set_direct_output()`을 사용한다.

## 4. 엔코더 속도와 거리 측정

- TIM5 CH1·CH2 Input Capture로 좌·우 HC-020K 펄스를 독립적으로 측정한다.
- `펄스 개수/고정 시간` 대신 최근 두 펄스 사이 시간을 이용해 RPM을 계산한다.
- RPM 공식은 다음과 같다.

```text
RPM = 60,000,000 / (펄스 간격[µs] × 한 바퀴당 슬롯 20개)
```

- 새 측정값 30%, 이전값 70%의 EMA 필터로 펄스 흔들림을 완화한다.
- 300 RPM을 넘는 값은 물리적으로 불가능한 노이즈 펄스로 보고 버린다.
- 200 ms 동안 펄스가 없으면 실제 RPM을 0으로 처리한다.
- 누적 펄스와 바퀴 지름 66 mm를 이용해 이동 거리를 계산한다.

## 5. 자이로 직진 유지

- MPU6050 시작 시 통신 확인, 2초 워밍업, 300회 자이로 영점 보정을 수행한다.
- 출발할 때 현재 방향을 yaw 0도의 기준으로 잡는다.
- yaw 오차를 `-180~+180도`의 가장 짧은 회전 방향으로 계산한다.
  따라서 359도와 0도의 차이를 359도가 아닌 1도로 처리한다.
- 방향 오차를 좌·우 목표 RPM 차이로 바꾸고, 직진 중 최종 좌우 차이를 최대 12 RPM으로 제한한다.
- 보정량은 한 제어 주기마다 최대 3 RPM씩 변하게 하여 갑작스러운 좌우 흔들림을 줄인다.
- 방향 오차 45도 강제정지는 사용하지 않는다. 큰 오차도 최저 RPM을 유지하며 계속 보정하고
  yaw와 좌·우 RPM 로그로 실제 복구 과정을 확인한다.
- X·Y 자세는 자이로와 가속도계를 결합한 상보 필터를 사용하고, Z(yaw)는 자이로를 적분한다.

## 6. 3방향 장애물 감지와 부드러운 회피

- VL53L0X는 정면 0도, 좌우 ±45도에 배치하고 XSHUT으로 `0x30/0x31/0x32`
  고유 주소를 부여한다.
- 센서별 최근 3개 결과의 중앙값, 새 측정 sequence, 마지막 갱신 시각을 관리한다.
- 정면 500 mm 이하의 새 결과가 3회 연속이면 장애물로 확정한다.
- 좌우 중 350 mm 이상 열린 쪽을 고르고, 차이가 100 mm 이하면 직전 성공 방향을
  재사용한다. 선택 방향은 회피 완료까지 latch한다.
- 회피가 시작되면 열린 방향으로 제자리에서 45도 회전해 초기 회피각을 확보한다.
  이후 정면이 가까워질수록 목표 Yaw 변화율을 초당 8→40도로 높이며 기본 속도를
  저전압에서도 멈추지 않도록 65 RPM을 유지한다.
- 왼쪽 회피는 오른쪽 센서, 오른쪽 회피는 왼쪽 센서를 안쪽 센서로 사용한다.
- 안쪽 센서로 약 400 mm 간격을 유지하다가 가까웠던 값이 1000 mm 이상으로
  3회 변하면 장애물 끝 후보로 판단한다.
- 끝을 확인한 실제 Yaw와 센서 설치각 45도로 열린 절대 방향을 계산하고, 정면
  센서가 같은 공간을 1000 mm 이상으로 다시 확인한다.
- 초기 45도 회전이 끝난 시점부터 약 1000 mm 전진하면 현재 세부 회피 단계와
  관계없이 전진을 멈추고, 제자리 회전으로 회피 시작 전 Yaw로 돌아간다.
- 정면 220 mm 또는 측면 180 mm 이하는 일반 회피보다 우선해 정지한다. 열린 탈출
  경로가 있으면 그 방향으로 45도 제자리 회전하고 400 mm 전진한 뒤 원래 Yaw로 복귀한다.
- 상태 12초, 전체 30초, 이동 2500 mm 제한을 넘거나 안전 경로가 없으면 정지한다.
- 모든 조정값은 `hw/rover_config.h`에 모여 있다. 상세 상태와 튜닝 방법은
  `docs/smooth-obstacle-avoidance.md`를 참고한다.

## 7. 과속방지턱 대응

- MPU6050의 Y축 기울기가 +10도 이상으로 100 ms 유지되면 오르막 이벤트로 판단한다.
- 오르막에서는 기본 목표 RPM을 30% 높이고, 최대 78 RPM으로 제한한다.
- Y축이 +5도 이하가 되면 내리막 구간으로 전환하여 기본 목표 RPM의 90%로 감속한다.
- 내리막을 지난 뒤 Y축이 `-5~+5도`에서 1초 유지되면 정상 주행으로 복귀한다.
- 센서값이 원점으로 돌아오지 않는 경우를 대비해 내리막 진입 3초 후 강제로 정상
  주행으로 복귀한다.
- 전체 방지턱 상태가 15초를 넘으면 상태 고착으로 판단하고 정상 상태로 초기화한다.
- 방지턱 이벤트 중 Z축 방향이 30도 이상 틀어지면 잠시 정지한 뒤 Z=0 방향으로
  복구한다. 고RPM 회전 관성을 고려해 ±12도 안에서 300 ms 유지하면 정상 주행으로 돌아간다.
- 방지턱 완료 뒤에는 정상 직진으로 복귀한다. 벽 횟수나 방지턱 순서를 세지 않으므로
  주행 중 벽 회피와 방지턱 통과 이벤트를 각각 반복할 수 있다.

## 8. 거리센서 오류 복구

- VL53L0X 측정은 긴 폴링 대기문 대신 여러 실행 주기에 나누어 처리하는
  non-blocking 상태머신을 사용한다.
- 실제 통신·측정 실패가 연속으로 발생하면 거리센서 오류로 전환하고 출발을 막는다.
- 거리센서 오류 상태에서 5초 안에 START를 세 번 누르면 다음 복구를 수행한다.

```text
차량 정지
 → XSHUT으로 거리센서 리셋
 → 센서 초기화
 → 1.5초 동안 정상 측정 확인
 → 성공 시 다음 START 명령 대기
```

- 자동 복구 시도는 최대 3회로 제한한다.
- 복구 실패 시 주행하지 않고 정지 상태를 유지한다.

## 9. 주행 상태와 로그

- 전체 상태는 `IDLE`, `DRIVING`, `OBSTACLE_AVOIDANCE`,
  `BUMP_HEADING_RECOVERY`, `STOPPED`, `ERROR` 중 하나로 관리한다.
- 주행 로그에는 현재 기능, 좌·정면·우 거리, X/Y/Z 자세, 좌·우 목표 RPM, 실제 RPM과
  모터에 최종 적용한 PWM 출력을 함께 표시한다. 공중 시험과 평지 시험의 차이를
  같은 형식으로 비교할 수 있다.
- 센서나 모터 오류는 평상시 주행 로그와 분리해 `[ERROR][장치]` 형식으로 출력한다.
- 장애물·방지턱·모터 재시동은 `[EVENT]`, `[RECOVERY]` 로그로 상태 전환 시점만 출력한다.

## 10. 빌드 모드

| 모드 | 목적 |
|---|---|
| `ROVER` | 전체 자율주행·리모컨 기능 |
| `HEADING_TEST` | 자이로 직진과 방향 보정 단독 시험 |
| `IR_TEST` | NEC IR 수신 단독 시험 |
| `VL53_TEST` | VL53L0X 거리 측정 단독 시험 |

네 모드는 모두 CMake 빌드가 확인되었다. 하드웨어 최종 검증은 바퀴를 띄운 시험,
평지 직진, 장애물 회피, 낮은 방지턱 순서로 진행한다.

## 11. 공통 긴급정지·복구 흐름

자이로 또는 모터·엔코더 피드백 오류로 정상 주행이 불가능하면 다음 순서로 처리한다.

```text
오류 감지
 → 모터 긴급정지
 → 구체적인 원인 로그 출력
 → 관련 하드웨어 재시동 및 대기 로그
 → 복구 완료 로그
 → 사용자가 차량 방향을 맞추고 Z 입력
 → START 입력 후 재출발
```

- 자이로 오류는 MPU6050 초기화·워밍업·영점 보정을 다시 수행한다.
- 모터·엔코더 오류는 PWM과 TIM5 Input Capture를 정지했다가 다시 시작한다.
- 회전 제한시간 오류는 모터·엔코더 재시동 후 MPU6050도 다시 보정한다.
- 복구 실패 시 차량은 정지 상태를 유지하고 배선·전원을 확인하도록 안내한다.
- 거리센서는 기존의 START 3회/XSHUT 복구 흐름을 유지한다.

## 12. 바퀴 공중 PWM-RPM 측정

UART에서 `c`를 한 번 누르면 차량이 정지하고 시험 안내가 출력된다. 양쪽 바퀴를
바닥에서 완전히 띄운 뒤 `c`를 한 번 더 누르면 측정을 시작한다. `x`는 즉시 취소한다.

```text
PWM 70 → 75 → 80 → 85 → 90 → 85 → 80 → 75 → 70%
```

각 단계에서 1초 동안 안정화한 뒤 2초 동안 좌·우 RPM의 평균·최솟값·최댓값과
좌우 차이를 출력한다. 상승 구간은 출발 특성, 하강 구간은 이미 회전 중일 때의 유지
특성을 확인하기 위한 것이다. PWM sweep 뒤 65/70/78 RPM 폐루프 검증까지 포함해
전체 시험은 약 36초가 걸린다.

공중 폐루프 검증 중에는 작은 자이로 오차가 좌우 목표 RPM 차이로 섞이지 않도록
방향 보정을 끄고 양쪽 바퀴에 같은 목표 RPM을 적용한다. 실제 평지 주행에서는 방향
보정이 다시 정상적으로 사용된다.

공중 시험은 모터와 엔코더 자체의 차이를 찾는 시험이다. 바닥 마찰, 차량 하중,
무게중심과 실제 yaw 보정은 포함되지 않으므로 공중 시험 뒤 평지 직진 로그도 별도로
측정해야 한다.

## 현재 하드웨어 범위와 남은 개선점

- 3센서 코드와 빌드는 준비됐지만 실제 센서별 주소·거리·장착각은 실물 시험으로 확인해야 한다.
- 낮은 방지턱은 거리센서 광선 아래에 설치하여 거리 회피를 발생시키지 않고 Pitch로만
  감지한다. 방지턱이 너무 높아 정면 센서에 잡히면 벽 회피가 안전 우선으로 실행된다.
- PID와 방향 보정 계수는 배터리 전압, 바닥 마찰, 차량 하중에 따라 실차 튜닝이 필요하다.
- Z축 yaw는 절대 방향 센서가 아니므로 장시간 주행에서는 드리프트가 누적될 수 있다.
